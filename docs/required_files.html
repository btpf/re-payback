Which original files are needed

For three different jobs: compiling the port, running it, and decompiling the original for further reverse-engineering work. The port ships no original game data; everything below comes from your own copy, kept in Payback Game + Updates/ and extracted to extracted/ (both git-ignored). Never commit any of it, nor the decompiled output in analysis/.

Compiling the game

Building needs no game files at all: install Rust (stable) and run

cargo build --release -p payback

Two build-time extras use game files if they are present, and are skipped otherwise (the build still succeeds):

ExtraReadsWithout it
Exe and window icon (crates/payback/build.rs)extracted/mac/Payback/Payback (OS X).rsrc, else the Amiga Payback.infono icon
Data staging next to the exe (target/<profile>/data/amiga, data/mac)the run-time files below, from extracted/ (or PAYBACK_DATA / PAYBACK_MAC_DATA)the exe looks for the data elsewhere at start-up (crates/payback/src/locate.rs)

The web build (tools/web/build_web.sh) is the same: the code needs no game files; the data pack it writes into web/dist/data/ uses the run-time list.

Running the game

Extract your copy once:

python tools/extract/extract.py       # Payback.iso + PaybackUpdate7.lha (+ OS4) -> extracted/game
python tools/extract/extract_mac.py   # PaybackMac.toast -> extracted/mac   (optional; pip install machfs)

extract.py copies the CD and lays Update 7 over it, giving the Update 7 install in extracted/game. The port then reads only the files below; the exact rules are the one list in crates/payback/data_files.txt, shared by the build's staging, tools/dist/stage_data.py and the web pack.

That is about 40 MB. The CD's audio tracks (music) are not on the data track; to hear music, rip them yourself into a Music folder (see docs/controls.md / the Music setup screen).

Mac data (optional): extracted/mac/Payback → data/mac

The same folder layout as the Amiga data. With it the port offers the Mac versions as settings (textures, models, blood, title screens, menu props, scenery), the Mac phrases, the MPEG intro film (Videos/payback_high_mpeg1.mpg, 44 MB) and the 31 bundled community maps (UserMaps/, 20 MB). About 90 MB. Without it everything falls back to the Amiga data.

Decompiling (further reverse-engineering)

The decompiles in analysis/ are regenerated by one command (docs/decompiling.md), which needs Docker and Python:

python tools/extract/extract.py
python tools/extract/extract_mac.py
docker build -t payback-re .
tools/ghidra/decompile_all.sh            # or name builds: 68k os4 macx mac9 mapedx scripts

You only need the archives for the builds you want: e.g. Mac work needs just PaybackMac.toast; Amiga 68k work needs the CD and Update 7. The data files themselves are not decompiled, but RE work on formats reads them from extracted/ too (tools/re/), and the symbol cross-reference is already committed in docs/xref/symbols.tsv.
