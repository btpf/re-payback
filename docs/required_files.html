Which original files are needed

For three different jobs: compiling the port, running it, and decompiling the original for further reverse-engineering work. The port ships no original game data; everything below comes from your own copy, kept in Payback Game + Updates/ (Amiga/, Amiga/Updates/, MacOS/; the same folders next to payback.exe for players) and extracted by payback-extract next to the exe, or by the Python scripts to extracted/ (all git-ignored). Never commit any of it, nor the decompiled output in analysis/.

Compiling the game

Building needs no game files at all: install Rust (stable) and run

cargo build --release              # payback.exe and payback-extract.exe

payback-extract also compiles the bundled UnRAR C++ source (the unrar crate), so it needs the C++ compiler that Rust's Windows (MSVC) toolchain already uses. The build creates the empty Payback Game + Updates/Amiga/Updates and MacOS folders next to the executables.

Two build-time extras use game files if they are present, and are skipped otherwise (the build still succeeds):

ExtraReadsWithout it
Exe and window icon (crates/payback/build.rs)extracted/mac/Payback/Payback (OS X).rsrc, else the Amiga Payback.infono icon
Data staging next to the exe (target/<profile>/data/amiga, data/mac)the run-time files below, from extracted/ (or PAYBACK_DATA / PAYBACK_MAC_DATA)the exe looks for the data elsewhere at start-up (crates/payback/src/locate.rs)

The web build (tools/web/build_web.sh) is the same: the code needs no game files; the data pack it writes into web/dist/data/ uses the run-time list.

Running the game

Put your files into Payback Game + Updates/ next to payback.exe and run payback-extract.exe from the same folder once:

FolderAccepted
Amiga/the CD: .iso (data track), .cue with its .bin file(s), one for the disc or one per track (the Redump set), or a .zip / .rar holding either
Amiga/Updates/PaybackUpdate7.lha (the OS4 port and Warp3D archives are listed but not used)
MacOS/PaybackMac.toast

It lists what it found, then writes the CD's Payback folder with Update 7 laid over it into data/amiga, the Mac CD's Payback folder into data/mac (both filtered by the one list in crates/payback/data_files.txt, shared with the build's staging, tools/dist/stage_data.py and the web pack), and the audio tracks into Music/NN.flac. It has its own ISO 9660, HFS, LHA and FLAC code, so it needs nothing else installed. Without the data, payback.exe shows a message saying the game files must be extracted, and closes.

From a source checkout the Python scripts unpack everything into extracted/ instead, which the build then stages next to the exe:

python tools/extract/extract.py       # Amiga/Payback.iso + Amiga/Updates/*.lha -> extracted/game, iso, os4, ...
python tools/extract/extract_mac.py   # MacOS/PaybackMac.toast -> extracted/mac   (optional; pip install machfs)

Which release is needed? Either one is enough (crates/payback/src/data.rs, locate.rs); the start-up search looks for both. --mac-only ignores the Amiga data to try a Mac-only setup.

The CD's audio tracks (music) are not on the data track: payback-extract takes them from a .cue + .bin image of the CD (tools/extract/rip_cd_tracks.py does the same from Python); or rip them yourself into a Music folder next to payback.exe (beside UserMaps/ and Saves/; not into data/, which the build regenerates). One file per CD track, named by track number (13.ogg, 13 - anything.flac, Track13.wav; WAV, Ogg, MP3 or FLAC). Track 1 is the data track: rip tracks 2–16 (13 menus, 16 Game Over, 8 Level/Game Complete, the rest the vehicles' radio stations; table in README.md “Music” and docs/re/frontend_audio.md §4.6). The Music setup screen says where they go when none are found.

Mac data (optional with the Amiga data): extracted/mac/Payback → data/mac

The same folder layout as the Amiga data (marker: CubeTextures/CubeTextureList.txt). With the Amiga data the port offers the Mac versions as settings (textures, models, blood, title screens, menu props, scenery), the Mac phrases, the MPEG intro film (Videos/payback_high_mpeg1.mpg, 44 MB) and the 31 bundled community maps (UserMaps/, 20 MB); without the Mac data everything falls back to the Amiga data. Alone it runs the whole game. Payback (OS X) (1.6 MB) is staged too: it holds the palette for a Mac-only setup. About 90 MB.
